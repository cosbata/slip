# RejectionBoard legacy materials

This directory preserves design/QA/prototype materials from the former `rejectionboard/` app after the product was consolidated under the final `slip` name and `slip.wtf` domain.

Canonical app directory: `slip/`  
Canonical brand: `slip`  
Canonical domain: `https://slip.wtf`

The former `rejectionboard/` source tree was not overlaid onto the live app because `slip/` already contains the current branding, domain metadata, and newer app behavior. The full former source tree is preserved at root-level `archive/rejectionboard-legacy-20260621/` for local reference.
